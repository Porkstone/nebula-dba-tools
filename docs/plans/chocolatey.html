Submit Nebula DBA to Chocolatey

Publish the 0.1.0 Windows portable application as nebula-dba-tools, with reproducible package sources and checksum-verified downloads.

Release and package

  1. Run lint, unit tests and the production Windows package build.
  2. Publish the executable and SHA-256 checksum to GitHub release v0.1.0, with nebula-dba-tools.exe as the application executable and nebula-dba-tools-0.1.0.exe as the portable download.
  3. Create Chocolatey metadata and scripts that download the x64 executable, verify its SHA-256 hash, provide a GUI shim and Start menu shortcut, and remove the shortcut on uninstall.
  4. Declare Microsoft ODBC SQLCMD (sqlserver-cmdlineutils) as a dependency. SQL Server remains a user-managed prerequisite.

Verification and submission

  1. Build the nupkg, inspect its contents, and test install and uninstall without changing databases.
  2. Publish package sources to the existing repository, then submit the nupkg to Chocolatey's community push endpoint using the privately supplied key.
  3. Update the existing 0.1.0 submission while it is in moderation, with the corrected executable filename and checksum. Preserve the version in the portable download filename.
  4. Report the submission response and package page. Chocolatey's automated checks and moderator approval happen after submission.

Credential handling

Read the publishing credential from the private secret file at submission time. Keep it out of source files, release assets and command output.
